# Privacy policy

Link Saver stores saved link addresses, titles, descriptions, file handles, drafts, and unfinished save requests on the user's device in browser extension storage and IndexedDB. It writes the user's selected PDF on that device. It does not operate an account or send this information to a server.

The `activeTab` permission reads the current tab's address and title after the user clicks the extension. Link Saver appears in the browser's toolbar popup. File access happens only after the user selects or creates a PDF in the browser's file picker.

The user can remove extension data by uninstalling Link Saver from the browser and can delete saved entries by choosing another PDF or removing the selected PDF.
